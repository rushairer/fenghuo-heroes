# fenghuo-heroes

《三國志列傳：亂世群英》clean-room 高清 Web 復刻。

## v0.2 方向修正

本版本不再把 MD 的 `320×224` 當作輸出清晰度，而只把它當作 **reference coordinate space**。

- 邏輯座標：320×224
- 內部高清畫布：1280×896（4×）
- 預設：高清抗鋸齒文字 / 邊框 / UI
- `H`：切換高清 / 像素預覽
- 遊戲流程、控件位置、菜單層級以原作畫面與中文版說明書為校準基準

目前最優先對齊的是原作開局與主循環，而不是自行設計現代 SLG UI。

## 鍵位

- 方向鍵：MD 十字鍵
- `Z`：A
- `X`：B
- `C`：C
- `Enter`：START
- `H`：高清 / 像素預覽

## 已恢復的原作結構

- 初期設定同屏布局：劇本 / 難易度 / 動畫 / 表示 / 君主
- 189 / 200 / 215 三劇本入口
- 初級 / 中級 / 上級
- 最多三位玩家君主
- 奇數月「視察情況」/ 偶數月「行軍」
- 視察情況：在地圖空白處按 C → 內政 / 外交 / 軍備 → 選本國城池 → 子命令
- 40 城高清地圖 scaffold
- 統治國一覽 / 全體地圖 / 武將狀態入口
- 行軍 → 攻城 → 一騎討ち垂直切片

## 版權邊界

倉庫不包含 ROM，也不重新分發原作點陣圖、音樂、音效或字庫。畫面結構與玩法按公開可觀察行為重建；高解析素材需要重新繪製或使用具備合法來源的用戶素材。
