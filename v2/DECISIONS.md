# DECISIONS.md — 架构决策记录

## 2026-05-17: 推倒重建决策

**决策：** 从当前项目（Hero/）中提取数据层，在 v2/ 子目录从零重建表现层。

**原因：**
- 原项目 src/main.ts 为单文件10177行，所有层级深度耦合
- 会战系统是12×8格子战棋，与原版《乱世群英》"军势对阵"结构性冲突
- 地图仅占左侧720×430而非原版全屏
- 继续修改会积累技术债务，不如重建模块化架构

**保留：** 静态数据（势力/城池/武将/道路）、算法逻辑（内政/外交/军事数值公式）
**重写：** 渲染层、会战系统、Phase状态机、UI组件体系

## 2026-05-17: 会战系统方向

**决策：** 新会战系统采用"军势对阵"模式，替代格子战棋。

**设计：**
```
双方各出数名武将带兵 → 按武力/统率/兵力/士气计算攻防 →
每回合选择：猛攻/坚守/单挑/撤退 →
损失按武将分摊 → 一方士气崩溃或总大将被俘则败
```
**不再使用：** 12×8格子、Unit/GridPosition、移动/技能/地形战棋系统

## 2026-05-17: 素材策略

**决策：** 代码可绘制的UI元素全部代码绘制；缺失图片用程序化占位；提示词集中管理。

**文件：** `asset-prompts/` 目录，按类别组织提示词供 GPT Codex 生成。
