# Parity Evidence Ledger — 2026-09-17

本文件记录本轮继续收敛时采用的可公开验证证据。它的作用是防止后续实现再次凭现代游戏习惯自行设计。

## 标题与开局流程

原版说明书公开扫描件描述：

1. 标题画面按 START。
2. 在 START / CONTINUE 中选择。
3. 选择 1~3 名玩家。
4. 进入初期设定。
5. 初期设定包含剧本、难易度、动画、表示速度、君主。

参考：

- https://segaretro.org/images/8/8a/Sangokushiretsuden_md_jp_manual.pdf
- https://www.myabandonware.com/game/sangokushi-retsuden-ransei-no-eiyutachi-84w

## 初期设定视觉

公开原版截图可确认：黑底、红金纹样边框、顶部四列剧本/难易度/动画/表示、189/200/215、初/中/上级、下方君主横向列表，当前值以青色高亮。当前实现以该布局作为 HD 几何基线，但文字使用中文版表达。

## 状况视察与主地图

原版说明书与玩家复盘可相互印证：

- 状况视察发生在正式命令之前。
- 方向键移动方框光标。
- 地图会随光标移动而滚动。
- A 可进入统治国一览。
- START 可查看全体地图。
- 主地图以地图画面为主体，并使用底部文字框提示状态。
- 在地图空白处按 C 可进入内政 / 外交 / 军备类别选择，随后再选择本国城池。
- 一回合只可选择内政 / 外交 / 军备中的一个类别，但同类别可继续让不同武将执行多个命令。

参考：

- https://segaretro.org/images/8/8a/Sangokushiretsuden_md_jp_manual.pdf

## 多人回合

原版支持最多 3 名玩家。实现规则改为：同一个月份内，所有人类玩家依次完成该阶段；最后一位玩家结束后，月份才推进。此前“每推进一次月份就轮换一个人类玩家”的实现已废弃。

## 单挑

公开玩家资料描述：A 打开单挑命令；B + 方向执行上/中/下段攻击；C 防御；命令包含说得、骂声、降参、退却一类行为；说得在对方体力较低时更容易成功。

参考：

- https://middle-edge-neo.jp/articles/4593/

当前实现已修正输入结构；具体伤害、速度、说得概率仍属于待实机标定项。

## 当前仍非 1:1 的部分

- 40 城位置目前仍是 scaffold，并非最终原版坐标。
- 原地图是可滚动的更大自由地图；当前仍将 40 城压在单屏逻辑空间中。
- 山脉、森林、河流仍为 clean-room 临时绘制。
- 标题五人群像仍为临时矢量人物，不是最终高清原创重绘资源。
- 武将数据、行军日数、粮草、战斗、攻城与单挑数值仍需录屏逐帧标定。

任何一项未完成时，都不得在文档中声称“已完成 1:1”。
