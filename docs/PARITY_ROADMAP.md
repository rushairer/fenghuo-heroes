# Parity Roadmap

## 目标定义

“1:1”在本项目中必须可验证，而不是凭印象判断。每个系统需要同时通过：

1. **Flow parity**：进入条件、返回路径、状态切换顺序一致。
2. **Input parity**：方向键 / A-B-C / Start 对应操作与长按、重复节奏一致。
3. **Layout parity**：在 320×224 逻辑画布中按截图坐标建立基准。
4. **Timing parity**：菜单响应、光标闪烁、动画帧、战斗节奏可测量。
5. **Rule parity**：资源、概率、AI、俘虏、死亡、继位、胜负规则有证据来源。
6. **Content parity**：只复刻可合法重建的结构与短功能标签；不分发原 ROM 资产。

## 当前明确的非 parity 项

以下内容在 0.1.0 中只是为了让架构可运行，不能当作原版事实：

- 12 城测试拓扑，不是最终原版全地图。
- 资源数值、指令成本、成功率不是原版校准值。
- 单挑人物目前是程序绘制的临时像素块，不是最终原创美术。
- AI 尚未接入。
- 行军暂时按“相邻城市路线”表达，未实现自由移动、村庄与运输队。

这些临时实现存在的目的，是先验证状态机和 CI，而不是冒充完成度。
