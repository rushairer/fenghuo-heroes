# 《三国志之乱世群英》HD Clean-Room Remaster — Art Bible v0.1

## 目标

本项目的视觉目标不是把 MD 像素机械放大，而是在保持原作可识别的构图、界面层级、地图阅读方式和 90 年代三国策略游戏气质的前提下，用原创高清素材重制。

- 原版截图/说明书用于观察构图、布局、功能、色彩关系和交互事实。
- 不从 ROM 提取、描摹或重新分发受版权保护的原始像素素材。
- 新素材可以使用 Image 2.5 生成底稿，再按游戏资产要求裁切、压缩、统一风格并接入。
- HUD、文本、按钮状态、光标、碰撞和游戏状态保持 code-native；角色、地形、城寨、旗帜、面板纹理等视觉资产优先图片化。

## 视觉方向

- 复古但高清：保留 MD 时代的构图密度与层级，不保留低清晰度本身。
- 历史三国感：须髯、冠饰、甲胄、披风、城寨、旌旗、山河。
- 不做现代手游霓虹/玻璃拟态，不做二次元偶像化，不做照片级皮肤写实。
- 地图以低饱和土色为主；标题、人物肖像允许更强的红金对比。

## 标题主视觉

目标构图：五位武将重叠群像，红/粉/绯色大背景，右侧蓝金织纹装饰边；人物层级必须一眼可辨，菜单覆盖层不得遮挡主体脸部。

Image 2.5 产出的标题母版只作为 clean-room 原创资产，不承担游戏按钮与文字交互；START / CONTINUE、光标和按键逻辑继续由 Canvas 绘制。

## 战略地图

- 逻辑世界继续使用 world-space + camera。
- 地表纹理、山脉、树林、河流、城寨、村庄、旗帜逐步改为高清图像资产。
- 40 城/村庄真实坐标未完成取证前，当前坐标只能称为 scaffold，不得标为 1:1。
- 不绘制现代网格，也不把工程 adjacency graph 当成可见道路。

## UI

- 黑底、双层金边、低饱和历史纹样。
- 面板优先设计为可 9-slice 的资源。
- 高亮以浅金/青白为主，不做霓虹光晕。
- 所有交互文字保持 code-native，避免图片里的文字导致可访问性和本地化问题。

## 肖像

- 母版建议 1024×1024，半身或胸像。
- 统一头部占比、视线高度和裁切安全区。
- 君主与部将使用同一画师语言；人物辨识来自脸型、须髯、头冠与服装轮廓，而不是现代手游特效。

## 资源接入原则

1. `asset-manifest.v1.json` 是运行时唯一图片资源入口。
2. 资产只有 `status: "ready"` 才会预加载；`planned` 不触发 404。
3. 图片加载失败不得阻断游戏；场景自动回退当前 Canvas clean-room 绘制。
4. 场景不得硬编码 `/assets/...` 路径，统一走 `AssetRegistry`。
5. 文件名带版本号，不覆盖历史母版。

## 第一批优先级

P0：标题主视觉、标题菜单框、基础 UI 面板、战略地图地表/山/河、城寨、行军旗。

P1：189 年七君主肖像、村庄、资源 icon。

P2：单挑人物与战场、攻击/受击特效、更多剧本角色。
